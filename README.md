# javaprojectsooheang

IntelliJ에서 `src/Main.java`를 실행합니다. 첫 메뉴에서 친구 등록, 목록 조회,
정보 관리, 궁합 테스트, 궁합 순위를 선택할 수 있습니다. `0`은 종료입니다.
친구 이름은 필수이며 생년월일과 MBTI는 Enter로 생략할 수 있습니다.
정보 수정에서 Enter는 기존 값을 유지하고 `-`는 선택 정보를 삭제합니다.
날짜는 `2007-03-15`처럼 입력합니다. 동명이인은 표시된 번호로 선택합니다.

궁합 테스트에서는 종류를 고른 뒤 직접 입력하거나 등록된 친구를 선택합니다.
순위는 이름과 생년월일 궁합만 제공하며 조회할 때마다 계산합니다.
동점은 공동 순위로 표시하고, 상위 5개 조합을 출력합니다.

이름과 생년월일의 숫자 배열을 사전순으로 배치한 뒤 기존 교차 및 반복 합산
계산을 적용합니다. 따라서 두 사람의 입력 순서를 바꿔도 점수가 같습니다.
기존 방식과 달리 일부 점수는 바뀔 수 있으며, 점수는 `점`으로 표시합니다.

친구 정보는 실행 위치의 `data/friends.json`에 저장합니다. 이 파일은
개인정보 보호를 위해 Git 추적에서 제외하며, 파일이 손상되면 덮어쓰지 않고 종료합니다.

MBTI 데이터는 `src/main/resources/mbti_compatibility.json`에 있으며,
`MbtiDataManager`가 처음 사용할 때 클래스패스에서 읽어 재사용합니다.
IntelliJ에서 `pom.xml`을 Maven 프로젝트로 열고 의존성을 가져오면
Gson과 resources가 자동으로 설정됩니다.
